一、安装与启动
运行 release\PowerCostAgent-Setup-<版本号>.exe（如 PowerCostAgent-Setup-0.3.0.exe），点击“安装到本机”。
安装完成后，桌面与开始菜单“所有应用”中出现“电力造价智能体平台”；Windows“设置 → 应用 → 已安装的应用”中显示版本与开发者，可在此卸载。
安装仅作用于当前 Windows 用户；安装程序包含 Python 运行时与必要依赖，无需显卡、Python 或 Node.js。
从桌面或开始菜单“电力造价智能体平台”快捷方式启动。
界面在独立 Windows 客户端窗口中打开，使用内嵌 WebView2，不打开外部浏览器。
电脑需要 Microsoft Edge WebView2 Runtime；现代 Windows 通常已安装。缺少时从微软官网下载：https://developer.microsoft.com/microsoft-edge/webview2/
原生“浏览”按钮可以选取本地文件夹。关闭客户端会结束由该窗口启动的本地服务；任务执行中关闭会询问确认。
界面以对话为中心，右侧“工作结果”可展开或收起，左侧项目栏也可折叠。聊天记录增量更新，空闲轮询不重复传输完整状态。
卸载可在 Windows 应用列表中执行。卸载保留项目数据。

程序安装目录：%LOCALAPPDATA%\Programs\PowerCostAgent
项目数据目录：%LOCALAPPDATA%\PowerCostAgent\data
当前源码开发版数据：本项目 runtime
安装包不含任何 API Key。密钥只保留在程序内存，退出后需重新填写。

用户登录：启动后先进入登录页，预置管理员账号 admin（初始密码由管理员另行告知）。
左下角显示当前用户与角色，点击“退出登录”或菜单“文件 → 退出登录”返回登录页；每次启动客户端需重新登录。
“技能开发与管理”及结果面板中的“技能代码”仅管理员可见可用；非管理员在对话中提出修改技能的要求也会被拒绝。
连续输错密码5次，该账号锁定5分钟。用户数据加密保存在项目数据目录 users.json，删除该文件会恢复为仅含预置管理员账号的初始状态。

代码保护：安装包中的项目 Python 模块已编译为本机代码（.pyd），技能模板和匹配引擎源码以加密文件（.pye）发布，
安装版保存的技能代码与版本记录同样加密。启动时校验程序文件完整性，检测到调试器或文件被替换即拒绝运行。

二、推荐演示步骤
1. 选择工作空间（工程目录），点击输入框下方的“资料清洗”。清洗在本机按规则完成，不调用在线模型。
2. 清洗结束后结果面板自动打开“清洗结果”：切换造价/清册数据，点击单元格修改名称、规格、单位、数量、层级、备注，可删除条目，点“保存修改”生效（源文件不改动）。
   “数据与来源”可查看选表依据、原文件、工作表和行号。
3. 模型设置选择“在线模型执行”，填写接口地址、模型名称及 API Key。DeepSeek 预设为 https://api.deepseek.com / deepseek-chat。
   其他兼容服务一般填写带 /v1 的基础地址；也支持完整 /chat/completions 地址。模型需要支持 JSON 输出。
4. 点击“数量评审”：弹出确认框，说明将发送给在线模型的数据与自动脱敏内容（站名换代号、单位名称与联系方式遮盖、不发送文件名和行号），点“是”才开始。
   数量评审依次完成候选配对与逐项核对，结束后结果面板自动打开“数量评审”。逐条复核后可点“价格评审”，用价格库信息价比对造价单价。
   “结果导出”按钮导出 Excel：结论汇总、数量评审明细、价格评审、清洗后的造价与清册数据。成果报告可在对话中输入“生成报告”。
5. 通过对话框输入“只处理 主变”“全部范围”“继续”“暂停”进行干预。
   “只处理”是对两侧原始字段及来源执行关键词过滤，不是智能专业归属推断；任一侧为空时停止并提示调整。
6. 点击记录查看配对、数量、换算说明和文件/工作表/行号。输入人工复核意见保存。
7. 导出 CSV 明细、JSON 审计包，或分别导出估算数据.txt、清册数据.txt。
8. “检查点与日志”可以恢复旧的中间结果。修改清洗结果、配对、范围或模型会使下游结果失效。

暂停语义：在当前步骤结束处停止，不强制切断正在进行的模型请求。
在线开放式对话检索知识库并提供引用；自然语言修改技能时实际改写 runtime/skills 下的Python代码，校验后生效。当前限定五个业务技能函数，不执行任意系统命令。

三、方案与平台映射
已阅读方案第3、4、5章的正文、表格及7张架构/流程图。
方案正文实际上有四项研究内容。平台将其组织为三个业务工作区：
1. 物资智能评审：研究内容一“数量核对”＋研究内容二“价格核对”。
2. 图纸识别与提资：研究内容三。
3. 物资价格数据库：研究内容四。
跨工作区共用本地数据、模型配置、技能接口、人工复核与结果记录。

四、实现结构
界面：左侧工程/技能入口，中间对话，右侧流程与数据画布。
运行：Windows桌面启动器 → 本地HTTP服务 → 技能函数 → 检查点与成果。
清洗技能：cleaning.py，读取XLSX/XLS，多行表头、合并单元格还原、来源行号保留。
数量技能：LLM_service.py 的 llm_pair → rule_refine → build_rows → review。
语义配对/分组/说明使用配置的在线LLM；数值比较、物理换算和护栏仍由确定性规则承担。
不导入 bgeKB_service_V9.py，不加载 BGE、reranker、torch、向量数据库。
原有 bgeKB_service_V9.py 保留供旧流程使用；平台入口已经替换为 LLM_service.py。
模型适配：LLM_service.py 所有6处请求统一使用 DEEPSEEK_URL / MODEL；环境变量 LLM_API_URL、LLM_MODEL 也可用于独立脚本。
模型配置的密钥不写入检查点，不读取已有 .dskey。
技能清单：skills.json；这些是平台技能契约，不是宣称已经安装的 Codex 技能。
存储：知识库使用SQLite FTS5中文双字索引，其余为单用户本地 JSON；每次写入采用临时文件替换，保留检查点快照。

五、哪些是真实可用，哪些是演示
真实实现：
- Windows安装包、桌面/开始菜单快捷方式、本地原生文件夹选择。
- XLSX/XLS清洗草稿、已有TXT导入、字段修正与来源记录。
- 原有LLM匹配脚本的分步接入，模型可配置，无GPU依赖。
- 检查点恢复、人工配对/复核、CSV/JSON导出。
- 价格JSON导入、完全同名同规格匹配、口径闸门、价差计算、阈值变更。
- 本地价格条目审核、环比预警、版本发布与回退。

仅演示或待接入：
- 离线模式只用保守的精确文本配对，绝不代表LLM效果；单侧记录也不能直接认定为工程漏项。
- 图纸界面中的示意图、识别值和置信度是合成样例，可人工修正、做接地套数/杆塔数校核并导出CSV提资草稿。
- 已接入独立在线视觉API，支持PDF前3页、PNG/JPG/WebP；DWG/DXF仍须先转换。未实现坐标级定位，置信度是模型自报。视觉接口已做模拟响应测试，尚未用真实视觉Key验证。
- 未实现公开信息价自动采集、PDF信息价识别、语义编码映射、税口径自动换算；目前采用标准JSON导入，不同口径阻止直接比较。
- 清洗尚未覆盖所有造价软件格式，金额守恒、成套层级关系和跨表重复仍需校核；多工程清册默认首个数量列。
- 单机单用户原型，不含企业多用户权限、数据加密、审计防篡改或生产级任务队列。
- 支持CSV/JSON、Word草稿、Excel明细。正式出版模板、PDF报告自动渲染尚未接入。
- 未进行专家盲测，不能据此宣称达到95%准确率。

六、数据边界
根目录提供的TXT样例包含315条估算与670条清册，并出现110kV设备，不能冒充鲁纳工程数据。
本次测试鲁纳文件夹：9个文件，清洗草稿626条估算、437条清册；具体数量会随源文件及清洗规则更新变化。
信息价示例、图纸示例与真实工程数据分离标记，演示数据不能用于实际核价。
所有源文件只读，输出另存；导出的修改结果保留原来源及人工修改理由。

七、研究路线调整
原方案采用本地向量模型、重排序及离线模型；本Demo按本次需求改为在线LLM匹配，同时接受内网兼容接口。
在线模式会向指定服务发送相关物资文本。正式业务应结合实际资料授权和部署要求确定模型服务。
本Demo是架构与交互验证，不替代原研究任务的验收。下一阶段应补齐真实图纸/信息价样本、解析器、专家标注和盲测。

九、新增的文档、知识库与视觉能力
在“电力知识库”的“上传规范或资料”中上传DOCX、XLSX、XLS、文本PDF、TXT、CSV、JSON（单文件8MB以内）。
读取后可查看原文，再按条款导入为规范文件或导入为自定义规则；扫描PDF请在图纸页使用视觉识别。
完成“成果报告”步骤后，物资核对表和评审报告草稿在结果面板“数据与来源”的“成果下载”中下载，需对照来源审核后使用。

知识库支持新建、文档分段导入、编辑、审核、启停、版本历史、本地检索。
初始8条知识为“自定义规则”（平台内置的核对口径与换算规则），均待专家审核，不冒充国家标准或已审定规则。
匹配先检索参考知识，再传给模型；结果详情展示ID、版本、来源和章节。
开放式问答返回可核查的知识库引用。检索参考与正式裁决依据必须由专家区分。
这是一套重新实现的本地技能与知识系统，不包含Codex的私有知识或模型参数。

视觉API与文字API分别配置，均使用国内在线服务。文字默认DeepSeek。
视觉首选阿里云百炼qwen3.8-max，中国内地地域；申请步骤：
https://help.aliyun.com/zh/model-studio/get-api-key。
API Base URL从百炼控制台复制，必须与Key地域、业务空间一致，不预填未知业务空间ID。
官方当前北京接口格式：https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1。
将WorkspaceId替换为实际ID；优先使用你控制台提供的完整地址。
也可填写豆包等支持图片输入与JSON输出的国内兼容接口。
此选型不代表已实测该模型在电力图纸上的排名；应使用同一批标注图纸比较。
PDF一次最多识别前3页，图片最大边约2000像素；大型密集图纸需分区导出清晰局部。
识别保留文件、页码、标注原文及模型名，字段需人工复核。模型自报置信度不是准确率。
