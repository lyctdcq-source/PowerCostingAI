# 版本管理

本地 Git 主分支 main，采用语义版本号；首次基线标签 v0.1.0。尚未连接远程仓库。

日常：git status → git diff → 运行测试 → git add 指定文件 → git commit。发布前更新 VERSION 与 CHANGELOG.md，验证安装包，再创建版本标签。已有版本的修复使用 git revert 提交，避免删除历史。

应用代码、SVG 图标、技能模板属于 Git；运行时技能版本与回退由平台 SkillStore 维护；知识条目版本在本地知识库维护。这三种历史相互独立。

忽略运行数据、工程样例、密钥、依赖目录和构建产物。初始提交沿用本机已配置的 Git 作者信息；后续可在此仓库设置自己的 Git 作者。
