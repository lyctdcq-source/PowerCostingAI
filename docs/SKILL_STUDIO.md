# 技能开发与管理

左侧“技能开发与管理”或视图菜单进入。技能分三类：

| 类别 | 内容 | 修改方式 |
|---|---|---|
| 流程技能 | 数据清洗、物资匹配、数量评审各步骤实际运行的代码（13个，按阶段排列） | 直接编辑代码，或用自然语言让模型生成修改草稿 |
| 规则技能 | 选表范围、清册排除、价格分档等业务规则（纯函数） | 直接编辑代码，或在对话中描述修改要求 |
| 自定义技能 | 自己开发的 run(data) 数据处理技能 | 见下文 |

## 流程技能

| 阶段 | 技能 |
|---|---|
| 数据清洗 | 清洗·选表与列映射、清洗·逐行提取（含原表成套行、编号上下级识别） |
| 公共规则 | 公共·文本与型号规则 |
| 物资匹配 | 匹配·候选配对、匹配·规则校验、匹配·成套项整体比对、匹配·核对单元分组 |
| 数量评审 | 评审·计量与换算、评审·逐行核对、评审·组级定档、评审·领域知识定档 |
| 流程编排 | 流程·匹配与评审编排（决定各步骤顺序） |
| 结果导出 | 导出·结果字段 |

成套项规则：可研整套计价的成套项（原表声明“费用包含/含以下/内含”，或以套、组计量且其下无另行计价子项的系统）与清册成套行及其组成件按多对多整体匹配，组成件不逐条匹配，与成套项取同一结论；找不到所属成套项的组成件按未匹配处理。由模型对整套做整体推理定档，配置差异写入结论。可研逐项计价的系统仍逐条核对。核对单元：成套项及其组成件用成套项名称，其余以清册原表直接上级章节分组，可研单侧用可研章节。

修改流程：选择技能 → 编辑代码或“生成修改草稿”（只生成草稿，不保存）→“校验并保存版本”。保存前依次检查 Python 语法、导入白名单与禁用名称、接口函数，再用内置样例把清洗、匹配、评审、导出整条流程跑一遍：结构问题（每条物资恰好出现一次、结论档位合法、导出列齐全）不通过则拒绝保存；行为与内置规则不同（改配、成套覆盖、计量性质、标准换算）只作提示。保存后受影响的结果自动失效：清洗类技能需“重新清洗”，匹配类技能需重新匹配，评审类技能需重新数量校核。每次修改生成新版本，可“回退该次修改”或“恢复内置版本”。

流程技能可导入 re、math、json、collections 等纯计算模块，不能使用 open、eval、exec、getattr 或双下划线属性；文件、网络、模型调用只能通过宿主提供的 ctx（ctx.llm_json、ctx.log、ctx.knowledge、ctx.setting）。这是代码审查约束，不是操作系统级沙箱，请只保存经过审查的代码。内置模板在 skill_templates/pipeline，运行时副本与版本记录在数据目录 pipeline_skills；未修改的技能随应用升级自动更新，已修改的保留用户版本并提示“内置有更新”。

## 自定义技能

点击新建，填写英文ID、名称和用途；可直接编辑代码，也可输入自然语言要求，让已配置文字模型生成代码与样例。AI输出仅为草稿，不自动保存或启用。

当前接口为 `def run(data)`，输入和输出都是 JSON 数据。支持数量、金额、字段映射及规则判断等纯数据操作；不支持任意模块、文件系统、网络或完整 Codex 技能包。Word/Excel与图纸工具仍通过平台已有业务工作区使用。

保存 → 运行测试 → 测试全通过 → 启用 → 输入JSON试运行。点击“放入对话框”会生成 `/技能 技能ID JSON输入`，发送后在对话中运行并显示结果。修改代码生成新版本、自动停用；回退也生成新版本。测试只证明样例通过，不等于专业正确性。

导出 `.skill.json` 技能包可在其他本平台实例导入；导入只解析和校验，不执行代码，默认停用。重复ID不会覆盖已有技能。导出的 skill 包含名称、说明、代码和测试，不含运行记录与 API 密钥。

代码先通过 AST 约束，再在独立进程运行，5秒超时终止，输入输出有长度限制。该限制不是操作系统级安全沙箱，仍应只使用可审查的代码。运行时技能和历史存储于数据目录 user_skills；应用源码继续使用 Git 管理。

## 语音输入

输入框右下角麦克风会聚焦输入框并调用 Windows 听写（Win+H）。Windows 听写面板负责开始/停止录音、麦克风权限和识别语言；识别结果先进入输入框，不自动发送。需要联网、可用麦克风和系统语音服务，音频由 Windows 语音服务处理，平台不录音或保存音频。当前不使用 DeepSeek / Qwen 进行语音识别。

微软说明：https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc
