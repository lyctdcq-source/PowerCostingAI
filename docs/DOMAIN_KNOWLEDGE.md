# 电力物资领域知识库（v0.2.0）

## 解决思路

物资匹配和数量校核中的多数差错，是因为缺少专业判断依据：哪些属性决定“是不是同一件物资”，成套项包含哪些组成件，吨与米、吨与套怎么按标准换算，哪些条目根本不属于实物工程量。知识库把这些依据从代码和模型的临时推断中分离出来，作为可审核、可追溯的数据维护，并接入清洗、配对、评审和结果展示四个环节。

构建原则：

1. **知识与代码分离**：知识保存在 `domain_knowledge/*.json`，专业人员可直接审阅和修订，用 Git 管理版本。
2. **逐条可追溯**：每条知识带编号、来源、证据级别、审核状态和审核记录；评审结论和报告引用所用知识编号。
3. **审核门控**：只有“已审核”知识可以改变评审结论；“待审核”知识只写提示。“已审核”条目必须记录审核人、日期和依据（结构校验强制检查）。
4. **参数来自标准，不从工程反推**：不能唯一确定的参数用区间保存，换算结果落在区间内判一致，落在区间外按最近端点计算差异。
5. **证据分级**：标准原文 > 标准公式 > 工程原表 > 专业经验；人工确认的对应关系单列。

## 组成

| 文件 | 内容 |
|---|---|
| `domain_knowledge/sources.json` | 来源登记（11项）、证据级别、审核状态与审核人说明 |
| `domain_knowledge/categories.json` | 品类本体（70个节点，61个可识别品类）、11个品类的身份属性、3类计量性质（拆除/利旧、服务调试、按项包干） |
| `domain_knowledge/parameters.json` | 材料密度、GB/T 3091-2015 钢管尺寸与镀锌系数、GB/T 706-2016 角钢理论重量（24种）、GB/T 156 系统电压与设备最高电压、电缆电压等级归并、E型电缆沟支架构成、架空导线结构 |
| `domain_knowledge/compositions.json` | 原表成套组成件抽取规则、规格声明附件规则、6个成套模板（27个组成件） |
| `domain_kg.py` | 知识引擎：校验、品类识别、身份属性比对、带出处的换算、冲突改配、单侧条目解释、图谱导出 |
| `knowledge_eval.py` | 离线回放：同一批数据分别在“无知识/有知识”下执行配对校验与评审，对比结论差异 |

## 平台接入点

1. **清洗**（`folder_cleaning.extract_table`）：成套项（带“费用包含/含以下/内含”等标记）之后的无单价子项作为“成套组成”随该项保留，并记录原表行号；按计量性质标记服务费用、按项包干、拆除利旧条目。条目不删除，人工验收基准仍为可研253/253、清册282/282。
2. **配对**（`LLM_service.llm_pair`、`rule_refine`）：排除已审核身份属性冲突的候选（如电缆芯数×截面不同）；对仍存在冲突的配对在同品类内重新分配；补配时跳过冲突项。
3. **评审**（`LLM_service.review`）：重量↔长度、重量↔件数换算优先使用知识参数，写明标准出处与算式，并给出反推线索（如反推密度与钢材吻合、反推格架单重相当于某规格角钢）；单侧条目按计量性质、原表组成件、规格声明附件、成套模板解释；新增结论“不参与核对”（服务费用、包干、拆除）和“待复核”（疑似成套组成）。领域知识已定档的行不再送模型改写批注。
4. **展示**：结果可视化默认“按物资品类”分组，可切换“按原表父级”；虚线表示知识认定的包含关系；详情弹窗与报告列出所用知识的出处、证据级别和审核状态。

## 鲁纳工程回放结果

运行 `python knowledge_eval.py`（输出 `qa/knowledge-eval.json`）。两次评审均离线运行、口径相同，差异只来自领域知识：

| 结论 | 无知识 | 有知识 |
|---|---|---|
| 一致 | 159 | 159 |
| 基本一致 | 70 | 85 |
| 部分一致 | 20 | 18 |
| 不一致 | 37 | 4 |
| 待复核（疑似成套组成） | — | 7 |
| 不参与核对 | — | 13 |

- 三条 ZR-YJV22 电缆的轮换错配在配对阶段按芯数×截面改配，数量全部一致。
- 11 条清册单侧物资对应可研原表中的成套组成件（主变保护屏 1.1～1.6、光传输设备“含以下”），其中光接口板 S4.1×4 对 L4.1×2 数量与规格不一致。
- 两条“母线绝缘护套”分别归入清册 TMY-125×10、TMY-50×5 铜母排规格中声明的附件。
- E-4-300 支架按规格型钢计算与可研一致；E-4-350、E-5-250 算出约20%差异，反推可研格架按∠40×4计列（规格写∠50×5）。
- 两条紫铜—50×5 反推密度为7850，疑似可研按钢材计重；三条镀锌钢管按现行 GB/T 3091-2015 比可研低约2%～2.3%（可研隐含系数1.06）。
- 清册原表“电气二次”第90行把5只电能表的名称写成“主变、35kV线路电能表屏”，品类比对给出提示。

## 扩充与维护

1. 新增条目必须填写 `id`、`source`、`evidence`、`status`；“已审核”条目还须填写 `review` 的 `by`、`date`、`basis`；来源须先登记在 `sources.json`。
2. 修改后运行 `python -m unittest test_domain_knowledge test_knowledge_integration`，再运行 `python knowledge_eval.py` 查看对结论的影响。
3. 品类按文件顺序匹配，新增具体品类须排在宽泛品类之前。

## 未决事项

- E-1-400 支架规格未写格架型钢，仍为“无法核实”；可研重量反推相当于∠50×5，需按设计图集确认。
- GB/T 1179-2017、GB/T 706-2016、GB 50217-2018 原文未取得，相关条目为 AI 核验，正式使用前建议专业人员对照原文复核。
- 铝包钢线 LB20A 密度（6.53 或 6.59 g/cm³）未定，以区间参与换算，不影响本工程结论。
- 品类本体按本工程变电部分建立，线路、土建物资尚未覆盖；`LLM_service.STRANDED_CORE_DENSITY` 中 LB27、LB35 的密度值与公开资料不符，尚未使用领域知识替代。
